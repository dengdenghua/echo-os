# Linux TV 交互预览

当前版本：0.3.7-tv.preview.20261106。平台顺序：Linux → Android TV（用户已确认）。

0.3.7 将 Linux 预览默认启动入口改为 TV 首页：上方应用预览、六个大卡片、方向键焦点和控制中心，参考 Apple TV 的 Top Shelf 结构。设置中可进入原桌面；知识库入口直接打开大屏 Echo 检索面板。继承 0.3.6 已验证的真实 Codex + DeepSeek 模型、检索和受控系统工具。最新本机证据位于 `E:/AGENT/analysis/tv-home-20261106`，真实模型完整验收位于 `E:/AGENT/analysis/linux-agent-live-20261106`。

## 已实现

- Linux TV 预览开机直接进入 `/#/tv`，使用现有登录边界。桌面左上 ECHO 菜单 → 大屏模式仍可返回；普通桌面可从 TV 控制中心打开。
- 独立首页、影视库、应用、搜索。方向键、Tab、确认与返回；弹层焦点隔离/恢复；异步按钮禁用时修复焦点丢失；支持减少动效。
- 真实媒体目录和中文名称搜索。轻量知识库无视频索引时，使用受后端授权约束的目录接口读取文件信息。限制为 100 个视频、20 个目录、4 层递归和约 5 秒发现预算（单次接口另有超时）；截断时明确提示。
- 浏览器播放适配器：流式读取授权媒体、暂停、前后跳转、播放错误与手动重试；按账号保存最多 50 条进度，继续观看；关闭时释放视频和临时 URL。
- Agent 浮层可从首页和播放器进入；调用现有任务 API，显示状态与工作台详情链接。尚未实现语音、专用媒体控制工具或 TV 内完整对话页。
- `core/tv/playback.ts` 的播放器接口独立于界面，预留 mpv 和 Android 后端。预留接口不表示原生后端已实现。

## 验收

2026-11-06，25 项单元/路由测试通过，TypeScript 与新增代码 ESLint 通过，生产前端构建通过。

独立浏览器集成覆盖方向键、中文搜索、焦点隔离与恢复、服务失败提示、1080p/4K 布局、真实生成短片解码/暂停、播放中 Agent 往返及连续 60 次焦点移动。该层服务响应使用测试模拟，不作为后端实测证据。

Linux 双核虚拟机使用原生 Electron 与真实后端，已验证：登录桌面、菜单进入 TV、Agent 健康状态、授权目录中的短片、视频解码与暂停、播放中 Agent 往返、断点续播、HTTP Range（206、64 字节）、真实任务提交和返回原桌面。测试短片为自生成 320×180 WebM。

**单引擎与真实模型**：普通对话、桌面和 TV 任务统一进入 Codex App Server。0.3.6 已接入已授权的 DeepSeek Flash，真实中文对话、知识库检索和系统工具闭环均通过；工具回合当前采用非推理模式。模型缺失时 TV 仍显示设置入口并禁止提交。0.3.7 继续复用该运行时，不新增执行引擎。
