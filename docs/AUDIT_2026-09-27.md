## 三、安全

### P1-1 · `ipython` 审批漏判（已复核）

- `approval_gate.py` 按工具名给风险分级。`shell_execution` 名单里有 `exec_shell / bash / run_python / python_exec / run_code …`，但**没有实际注册的 `ipython`**（`write_skills.py:363`）。
- 结果：`ipython` 落到低风险，默认策略直接放行，不需要人工审批，但它能执行任意 Python 子进程。
- 安全审查推出的一条提权链（**未端到端实跑**）：家庭成员和 admin 在 runtime 层是同一个角色（`local_auth/config.py:105`）。Landlock 沙箱对 `/` 开放读取（`sandbox.py:750`）。于是 Agent 可以读 `/data/appliance-auth.json` 拿到 `jwt_secret`，伪造 `sub=local:admin` 的 token。
- 就算这条链不完整，单是"任意代码执行不需要审批"本身就是 P1。
- **修复**：把 `ipython` 加入 shell 名单，更稳妥的做法是按 `all_skills` 的 `group == "shell"` 判定，别再维护一份手写名单。然后补一条回归测试：遍历所有 `shell` 组工具，断言风险为 high。

### P1-2 / P1-3 · 设备互联（已解决 ✅）

- **P1-2 身份冒用（已解决 ✅）**：
  - 独立 Echo AI 在共享 token 模式（`ECHO_TENTACLE_TOKEN`）下缺乏对等身份绑定，已在 `ws_server.py:_handle_peer_call` 中强制要求每台设备具备独立凭据（`is_per_device_auth=True`，由 `appliance/device_link.py:_install_managed_auth` 注入）。
  - 若在开发/测试环境下未启用 per-device 凭据，需显式声明 `ECHO_ALLOW_INSECURE_SHARED_TOKEN_PEER_CALLS=1`，否则调用直接被门禁拒绝（错误码 `-32098`）。
- **P1-3 绕过租约与回执缺失（已解决 ✅）**：
  - `device/call` 统一交由 `coordinator.device_executor`（`DeviceActionExecutor`）处理。
  - 在下发调用前严格核验目标设备当前租约锁（`pool.lock_holder(target)`），防止被其他并发任务插队调用（冲突时返回 `-32016`）。
  - 成功执行后自动生成 `ExecutionReceipt` 并归档入账本（`coordinator.device_executor.ledger`），回执 ID 随结果一同透传回调用方。
  - 已补全完整回归测试（`tests/test_device_interconnect.py`）。

### P1-4 · Electron

- HEAD 版的问题：没有 `will-navigate` / `will-redirect` 拦截；除 nativeGlass 之外，其余 IPC 都不校验 `event.sender`；`desktop:openItem` 会对任意路径调 `shell.openPath`。
- 一旦渲染进程被导航到外部页面或出现 XSS，就能在客户端执行本机代码。
- 工作区的 `safe-external-url.cjs` 已经接到 `app:openExternal` 和 `setWindowOpenHandler`，能挡住 `javascript:`、`file:`、`data:`、大写协议和 UNC 路径。但还剩两个口子：
  - 它校验的是规范化后的 URL，交给 `openExternal` 的却是原始字符串。`"ht\ttps://…"` 和 `"https:\\\\evil\\share"` 都能通过，应改为传 `new URL(raw).href`。
  - `openItem` 和 `will-navigate` 仍然没有防护。

### 已核实做对了的控制

- **认证**：JWT 固定 HS256、`compare_digest`、强制 exp/iss、iat 下限；bcrypt 加 72 字节上限；登录按 IP 加用户名限速；各类 token 都用 `secrets` 生成、常量时间比较。
- **网络暴露面**：Host/Origin 校验防 DNS 重绑定和 CSRF，WebSocket 同样校验 Origin；无认证时拒绝绑定非回环地址；compose 默认绑 `127.0.0.1`；没开 CORS。
- **文件与压缩包**：文件管理器能拒绝 `..`、反斜杠和符号链接逃逸；公开分享用 `O_NOFOLLOW` 加 inode 核对；所有解压点都防 zip-slip。
- **镜像与容器**：Hub 镜像按 sha256 固定；docker.sock 放在带 token 的代理后面。
- **Electron**：`contextIsolation` 开，`nodeIntegration` 关，密码库用 `safeStorage`。
- **设备互联**：托管模式按设备做 HMAC 认证；邀请一次性且会过期；ASGI 首帧 10 秒超时、单帧 1 MiB 上限；`tool/result` 绑定到发起连接；`device_client._path` 先 resolve 再做包含判断，并拒绝 ADS。
- **交接核对**：确实会强制执行，`advance` 要求 `result_review` 为 achieved 且 revision 一致；审批绑定到精确参数的信封。
